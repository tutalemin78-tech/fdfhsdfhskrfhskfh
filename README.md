# SendFlow — обновление

Начните с **README_UPDATE.md**: возможности, ограничения, переменные окружения, резервное копирование, миграции и проверка перед запуском.

- TEST_REPORT.md — что проверено локально и что ещё требует реальных Telegram-аккаунтов.
- CHANNEL_POST.md — готовый текст для канала, публиковать после установки и проверки.
- .env.example — настройки без секретов.
- requirements.lock.txt — версии библиотек тестовой сборки.
- tests/ — автоматические тесты на отдельной локальной PostgreSQL БД.

Сборка не содержит рабочего BOT_TOKEN, production-ключа шифрования или реальных сессий.
